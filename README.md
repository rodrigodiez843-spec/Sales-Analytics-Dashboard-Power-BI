# # 📊 Sales Analytics Dashboard – Power BI
El proyecto consiste en el desarrollo de un dashboard analítico en Power BI para evaluar el desempeño comercial de una empresa distribuidora mayorista de calzado en Argentina, durante el período 2023–2025. El objetivo es transformar datos transaccionales en información clara y accionable, facilitando la toma de decisiones comerciales y estratégicas

→ Objetivos del análisis

Analizar la evolución de ventas y rentabilidad
Identificar regiones con mayor volumen comercial
Evaluar el desempeño de productos y categorías
Analizar el comportamiento de clientes y vendedores


🛠️ Stack tecnológico

Power BI (visualización y dashboard)
DAX (medidas y métricas analíticas)
Power Query (limpieza y transformación de datos)
Modelo de datos tipo estrella


→ Modelado de datos

Se diseñó un modelo relacional tipo estrella, donde:

La tabla Ventas actúa como tabla de hechos
Las dimensiones incluyen: Clientes, Productos, Vendedores y Provincias

Este enfoque permite realizar análisis eficientes y escalables sobre métricas comerciales.


► Procesamiento de datos

Se aplicaron transformaciones clave para asegurar calidad e integridad:

Corrección de fechas inválidas
Eliminación de valores inconsistentes (cantidades negativas)
Gestión de claves foráneas inválidas
Normalización de campos descriptivos
Validación de dominios de negocio



📈 Dashboard

El dashboard permite explorar la información mediante:

Segmentación por año, región y categoría
Análisis temporal de ventas
Comparación de rentabilidad
Visualización geográfica
Análisis de clientes y vendedores
📊 Métricas desarrolladas

Total de ventas
Cantidad de ventas
Unidades vendidas
Beneficio y margen (%)
Variaciones interanuales (2023–2025)


🔍 Insights principales

📍 Las regiones Centro y NOA concentran el mayor volumen de ventas y beneficio
👟 La categoría Deportivo lidera el negocio
🧑‍💼 Existe una fuerte concentración de ingresos en pocos clientes (modelo B2B)
🏆 Algunos vendedores concentran gran parte de la facturación
📉📈 Se observa una caída en 2024 con recuperación en 2025
